 Question02: What is the difference between Array.Clone() and Array.Copy()? 
 Array.Clone() => object member function creates a shallow copy of the array
 Array.Copy() => static method that copies elements from one array to another
 ------------------------------------------------------------------------
 Question03: What is the difference between GetLength() and Length for multi dimensional arrays? 
 GetLength() => returns the number of elements in a specified dimension of the array
 Length => returns the total number of elements in all dimensions of the array
 ------------------------------------------------------------------------
 Question04: What is the difference between Array.Copy() and Array.ConstrainedCopy()?
 Both of them do the same thing:
They take elements from an array and put them into another array.

Array.Copy() => If an exception occurs during copying some elements might have already been copied in other words the destination array ends up in a partially copied state
Array.ConstrainedCopy() => It ensures that the operation either succeeds completely or the destination array remains unchanged if an exception occurs
